# 작가에게 건네기 — 덮어쓰기 막기 · 판 번호 · 안내문 · 릴리스 · Git 차림 (WR0–WR5) — 2026-11-19

**소유자**:
- 「이후에 진짜로 시나리오 작가가 바로 쓸 수 있게 준비를 합시다.」
- 작가의 PC는 **Windows**. 앱은 **GitHub 릴리스**로 건넨다. 작가가 쓴 프로젝트는 **Git(GitHub)** 으로 주고받는다.
- 꾸러미에 **안내문**을 넣는다. 실제 게임 프로젝트는 지금 소유자의 PC에만 있다 — 비공개 저장소는 소유자가 만든다.

앞선 일: `writer-app-orders.md`(WA0–WA9 — 맥 최소 지원 · 트랙패드 · 이름과 아이콘), `usability-orders.md`(UX0–UX32).

> **상태: 툴 쪽은 끝(2026-11-19) — 소유자가 할 일이 남았다**(4절). 여섯 단계를 다 했다 — 진행 기록.
