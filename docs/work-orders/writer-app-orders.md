## 1. 지금 · 정한 것

| # | 지금 | 정한 것 |
|---|---|---|
| 맥의 키 | 창의 단축키가 **Ctrl만** 본다(`MainWindow` · 장면 메모). 맥의 ⌘는 Ctrl이 아니라 따로 오는 키(Meta)라 ⌘S · ⌘Z가 듣지 않는다 — 글 칸만은 Avalonia가 ⌘Z를 받아, 같은 키가 자리마다 다르게 군다 | **맥에서는 ⌘를 Ctrl처럼 듣는다** — 저장 · 되돌리기 · 다시 실행 · 메모 넣기(⌘Enter). Ctrl도 그대로 듣는다(화면 곳곳의 「되돌리기(Ctrl+Z)」가 맥에서도 참이다 — 글을 OS마다 가르지 않는다). 맥의 다시 실행 ⌘⇧Z도 듣는다(Windows의 Ctrl+Shift+Z는 7절 AU 그대로 — 되돌리기). File 메뉴의 단축키 글과 설정 창 단축키 표는 맥에서 ⌘로 보인다. 규칙은 `PlatformKeys` 한 벌 |
| 맥의 delete | [대본] 판의 카드 지우기가 `Delete` 키만 듣는다. 맥북의 delete는 그 키가 아니다(⌫ — Backspace. `Delete`는 fn+delete) | 맥에서는 ⌫도 고른 카드를 지운다(글 칸 밖 · 묻지 않는다 · 되돌리기 한 칸 — `Delete`와 같다). Windows의 Backspace는 그대로 아무 일도 없다 |
| 휠 배율 | 휠 신호 하나마다 ×1.15(올림) · ÷1.15(그 밖)다 — 신호의 **크기를 보지 않는다**. 트랙패드는 한 번 쓸 때 잔 신호를 수십 개 보내 배율이 튀고, **가로로 쓸면**(세로 값 0) 「올림이 아니다」로 읽혀 **축소된다** | 배율은 신호의 크기에 비례한다 — 1.15^(세로 값). 마우스 한 칸(±1)은 지금과 같고 잔 신호는 그만큼 조금 움직인다. 세로 값이 0이면 배율이 아니다(가로 휠은 판이 가로로 스크롤한다). 두 판([구성] · [대본]) 한 벌(`BoardWheel`) |
| 휠로 판 옮기기 | 판 옮기기는 **가운데 단추 끌기뿐**이다 — 트랙패드 · 매직 마우스에는 가운데 단추가 없다. 두 손가락 쓸기(= 휠)는 배율이 가져간다 | 이 PC의 앱 설정 **「휠로 판 옮기기」**(설정 창 「기타」 · 누르는 즉시) — 켜면 휠(두 손가락 쓸기)은 판을 옮기고 배율은 Ctrl(맥은 ⌘도)+휠이다. 끄면 지금처럼 휠이 배율이다(Ctrl을 눌러도 같다 — 2026-08-18 미팅의 결정 그대로). **처음 값은 맥만 켜짐**(맥의 손은 쓸기 = 옮기기다), 그 밖은 꺼짐 — 휠 마우스와 터치패드를 신호로는 가를 수 없어 스위치로 둔다(Windows 노트북 작가가 켠다). 맥 트랙패드의 **집기**는 스위치와 무관하게 배율이다(Windows 터치패드의 집기는 Ctrl+휠로 오므로 어느 쪽이든 배율) |
| 이름 | 창 제목 「VnTool」 · 실행 파일 `Vn.App.exe` · 꾸러미 `VnTool-win-x64.zip` | 보이는 이름 **「스토리 디렉터」**(저장소 이름 story-director 그대로 — 연출 툴 compositor와 짝) · 실행 파일 `StoryDirector` · 꾸러미 `StoryDirector-win-x64.zip`. ⛔ **이 PC의 설정 · 로그 폴더 이름 `VnTool`은 그대로 둔다** — 바꾸면 이미 쓰던 작가의 최근 프로젝트 · 글꼴 설정이 새 판에서 사라진다(앱의 이름과 저장 자리의 이름은 다른 것이다). 솔루션 · 프로젝트 · 네임스페이스(`VnTool.sln` · `Vn.App`)도 그대로 — 안의 이름이다 |
| 아이콘 | 없다(창 · 실행 파일이 기본 그림) | 갈래 그림 — 카드 하나에서 두 카드로 갈라지는 길(이 툴이 쓰는 것: 대사 카드와 선택지). 원본 `Assets/app-icon.png`(1024) 하나에서 Windows `.ico` · 맥 `.icns`를 굽는다(`tools/make-app-icons.py`) — 그림을 바꾸려면 원본을 갈고 다시 굽는다. 창 · 실행 파일 · 맥 꾸러미가 쓴다 |
| 맥 꾸러미 | 없다 — 배포 스크립트 · CI가 Windows뿐이다 | `publish-macos.sh` — .NET을 품은 `StoryDirector.app`(Apple 칩 `osx-arm64`가 기본, 인텔은 인자 `x64`)을 zip으로. CI에 macOS 작업 — 빌드 · 테스트 · 꾸러미 굽기 · 켜 보기 · 꾸러미 올려 두기. **서명 · 공증은 하지 않는다**(Apple 개발자 계정이 든다 — 「가볍게 최소로」의 밖). 작가는 처음 한 번 「시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기」를 지난다 — 안내문에 적는다 |

하지 않는 것: 맥의 서명 · 공증, 맥의 메뉴 막대로 File 메뉴 옮기기, 버전 번호, 자동 업데이트, Windows 서명 · 설치 프로그램.
