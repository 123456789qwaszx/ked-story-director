# [구성] 탭 — 하이어아키에 이름, 카드 칩에서 「장면」을 뗀다 (H0–H2) — 2026-11-18

**소유자**:
- 「구성 탭의 하이어 아키의 장면과 챕터 옆에 DisplayName이 적혀있도록 해주십시오. 에피소드 처럼.」(H1)
- 「구성탭에서 노드들을 보면 현재는 "장면 시작점" "장면 - scene01" 이렇게 되어있는데 장면이라는 단어는 중복이라 필요없습니다. "시작점"
  "{장면ID}"가 표시되도록 고쳐주십시오.」(H2)

> **상태: 끝 (2026-11-18).**

## 1. 지금

- [구성] 하이어아키는 ID로 선다. 에피소드 줄은 ID 옆에 곁글로 제목(비었거나 ID와 같으면 없음)이 붙는다. 챕터 줄의 곁글은 늘 「챕터 조건 스탯」
  (`StoryHierarchy.ChapterDetail` — 셸이 [구성]에만 정한다), 장면 줄의 곁글은 메모가 있을 때 「메모」뿐이다 — 이름이 보이지 않는다.
- [구성] 판의 카드 머리 칩: 장면 시작 에피소드에 「장면 시작점」, 모든 에피소드에 「장면 · {장면ID}」.
