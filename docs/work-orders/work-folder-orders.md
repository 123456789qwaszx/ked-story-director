# 작업 폴더 · 설정의 「내보내기」를 접고, 형식을 누르면 파일을, 보낼 곳은 경로 칸으로 (T0–T4) — 2026-11-18

**소유자**:
- 「File과 설정 사이의 "챕터진행"버튼의 이름을 작업 폴더로 바꿔주십시오.」(T1)
- 「설정창 속에서 내보내기의 내용은 접을 수 있도록 해주십시오.」(T2)
- 「진행 JSON, 장면 파일, 대사 Yarn은 솔직히 뭐가 뭔지 모르겠으니, 저기서 각각을 클릭하면 작업 폴더가 열리면서 해당하는 파일이 선택되거나 열리도록
  해주시고」(T3)
- 「그 옆쪽에서 고르기를 통해 연결할 폴더를 고르는데, (보내지 않음)으로는 뭐가뭔지 잘 이해가 안 가니, 다른 윈도우 탐색기처럼 경로를 연결하는 형식을
  맞춰주십시오.」(T4)

> **상태: 진행 중.**

## 1. 지금

- 위 띠 [📂 챕터진행](`OpenExportFolderButton`)은 프로젝트 폴더의 `exported/`를 연다 — 진행 JSON(`{챕터}.progression.json`) · 장면 파일
  (`{챕터}.scenes.json`) · 대사 Yarn(`yarn/`)이 저절로 나가는 자리다.
- [⚙ 설정] 창은 묶음 둘(「이 프로젝트」 · 「내보내기」)이 늘 펼쳐져 있다. 「내보내기」는 형식마다 한 줄 — 이름 글(「진행 JSON → 게임 폴더」 · 「장면 파일」 ·
  「대사 Yarn」), 보낼 곳 글(프로젝트 폴더 기준 상대 경로, 없으면 「(보내지 않음)」, 없는 폴더면 「⚠ 없는 폴더 — …」), [고르기…], [✕].
  보낼 곳은 그 줄에서 적지 못하고 폴더 고르기 창으로만 정한다.

## 2. 단계

| # | 일 |
|---|---|
| T0 | 지시서 |
| T1 | **[📂 챕터진행] → [📂 작업 폴더]** — 하는 일(`exported/`를 연다)은 그대로. 단추 이름(`WorkFolderButton`) · 툴팁 · 안내 문구 · 시험 · 문서에서 그 폴더를 「작업 폴더(exported/)」라 부른다 |
| T2 | **설정의 「내보내기」를 접는다** — 묶음 머리를 눌러 접고 편다(처음에는 접혀 있다 — 자주 고칠 것이 아니다). 머리에 지금 보내는 형식 수를 적어 접혀 있어도 알 수 있게 |
| T3 | **형식 이름을 누르면 작업 폴더에서 그 파일을 보인다** — 「진행 JSON」 · 「장면 파일」은 지금 챕터의 그 파일을 골라 둔 채 작업 폴더를 열고(Windows 탐색기 `/select` · macOS `open -R`, 그 밖에는 폴더만), 「대사 Yarn」은 `yarn/` 폴더를 연다. 지금 챕터의 파일이 없으면 그 형식의 다른 파일, 그것도 없으면 아직 나간 것이 없다고 말한다. 이름마다 무엇인지 툴팁. 시험 · 문서 |
| T4 | **보낼 곳은 탐색기처럼 경로 칸 + [찾아보기…]** — 줄마다 경로 칸(절대 경로가 보인다 · 적거나 붙여 넣을 수 있다 · 비우면 보내지 않는다 — 자리표시가 그렇게 말한다 · 칸 안의 ✕로 비운다)과 [찾아보기…](폴더 고르기 창 — 고른 경로가 칸에 든다). Enter · 초점 이탈 · [확인]이 칸의 글을 반영한다(상대 경로를 적으면 프로젝트 폴더 기준). 없는 폴더는 칸 아래에 알린다(만들지 않는다). 저장 형식(`runtime.target.json` — 프로젝트 폴더 기준 상대 경로)은 그대로. 「(보내지 않음)」 글 · [고르기…] · [✕]는 걷는다. 시험 · 문서 |
