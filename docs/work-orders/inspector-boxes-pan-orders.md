# [구성] 글 칸 반영 · Esc · 가운데 버튼 끌기 · 미니맵 즉시 (J0–J4) — 2026-11-18

**소유자**: 「구성의 ID칸은 다른 곳을 눌러도 반영되도록 해주십시오. Esc를 눌러서 되돌리는 건 대본탭에서 이미 하고 있다면 대본탭과
맞춰주십시오. 구성판에서도 가운데 버튼 끌기로 판이 움직여지도록 수정합시다. 또 대본탭 미니맵 보이기는 체크박스 형식으로 해주십시오.」
물어 정한 것(2026-11-18):
- 미니맵 → 「설정 창 · 누르면 바로」.
- Ctrl+Shift+Z → 「그대로 둔다」 — 창의 키 처리가 Shift를 보지 않아 Ctrl+Z처럼 동작한다. 추가한 단축키가 아니다.

> **상태: 하는 중.**

## 1. 지금

- [구성] 인스펙터의 ID 칸(에피소드 · 챕터 · 장면 · 분기 카드)은 Enter로만 바뀐다. 다른 곳을 누르면 적던 글이 그냥 남거나 다음 선택의 값으로 덮인다.
- [구성] 인스펙터의 글 칸은 Esc로 되돌아가지 않는다.
  - 다른 칸들(잠금 안내문 · 조건 식 · 스탯 표 · 캐릭터 키 · 스탯변화 숫자)은 Enter · 초점을 잃을 때 낸다.
  - [대본]의 글 칸은 Enter 넣기 · Esc 넣기 전 글로 · 다른 곳 누르기 넣기다.
- [구성] 판의 가운데 버튼 끌기는 판의 빈 곳에서만 된다. 선 · 문구 · 점 위에서 시작하면 그 자리가 누름을 먼저 먹어 판이 안 움직인다.
  - [대본]은 판이 누름을 먼저(터널) 받아 어디서 시작해도 움직인다.
- 설정 창 「기타」의 「[대본] 탭 미니맵 보이기」는 [확인]을 눌러야 반영된다.

## 2. 정한 것

- **[구성] 인스펙터 글 칸은 [대본]과 같은 규칙** — Enter 넣기 · 다른 곳 누르기 넣기 · Esc 넣기 전 값으로(초점은 그대로).
  - ID 칸도 초점을 잃으면 바꾼다. 받지 않으면(같은 ID가 있다 · 비었다) 칸이 지금 값으로 돌아가고 까닭을 상태줄이 말한다.
- **고름이 바뀌기 전에 적던 칸을 먼저 낸다** — 판의 카드 · 선 · 점은 초점을 가져가지 않는다. 그래서 고르기의 첫머리에서 초점을 받이로 옮겨,
  적던 칸이 **바뀌기 전의 대상**에 들어가게 한다.
  - 판을 누르기 전에 적던 에피소드ID가 다음 카드에 들어가면 안 된다.
  - 그 에피소드를 다시 누른 것이면 새 ID로 고른다.
- **[구성] 가운데 버튼 끌기**는 [대본]처럼 판이 누름을 먼저(터널) 받는다 — 선 · 문구 · 점 · 카드 위에서 시작해도 판이 움직인다.
- **미니맵 체크는 누르는 즉시 반영한다** — [확인]을 기다리지 않고, [취소]로 되돌아가지 않는다. 「기타」 머리의 안내를 그렇게 고친다.
- 단축키 표를 맞춘다 — [구성] 판의 가운데 단추 예외 · 「Enter만」 줄을 걷고, Esc 되돌리기는 두 탭 모두라고 적는다.
