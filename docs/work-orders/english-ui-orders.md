# 영어 화면 (E0–E7) — 0.3.0

**소유자**: 「이제 다음으로 영어 화면 지원을 하려고 하는데, 견적부터 재줄래?」 → v0.2.0을 먼저 내고 → 「영어화면 관련해서, 미리 해두는 건데,
가능하면 범위, 메뉴, 단추, 안내문, 검증 보고 문장, 작가 설명서 까지 모두 해두는 게 좋겠습니다.」(2026-11-23)

> **상태: E0 — 용어집([`english-ui-glossary.md`](english-ui-glossary.md))을 소유자가 본다.** 확인을 받은 뒤 E1부터 한다.

## 1. 정한 것 (2026-11-23)

- **왜** — 미리 해 둔다. 지금 영어 화면을 쓰는 작가가 있는 것은 아니다.
- **범위 — 전부**: 메뉴 · 탭 · 단추 · 칸의 힌트와 툴팁 · 안내문(GuideLine) · 상태줄 · 확인 창 · 설정 창 · **검증 보고 문장**(고치는 법 상자 ·
  거절 사유 포함) · **작가 설명서**(`docs/작가에게.txt` = 꾸러미의 「먼저 읽어주세요.txt」 · `docs/writer-guide.md`).
- 대본 데이터의 언어별 칸(기본 `ko-KR`)은 이미 있다 — 이 일은 **툴 화면의 언어**다. 영어 대사는 지금도 쓴다.

### 2026-11-25 — 시작하며 물은 것

- **처음 언어** — **PC(OS) 언어를 따른다**(한국어 PC면 한국어, 그 밖은 영어). 설정 창에서 바꾸고, **다시 켤 때** 바뀐다(창을 그 자리에서 다시 짓지 않는다).
- **데이터에 적히는 낱말** — **한국어 그대로**: `NewNames`(「새 에피소드」 · 「새 장면」 · 「새 챕터」 · 「새 분기」), `ChapterSheetNames`(「에피소드」 · 「간선」 · 「조건」 · 「스탯」 …).
  화면 언어를 바꿔도 저장된 데이터가 달라지지 않는다.
- **내보내는 파일** — **한국어 그대로**: Yarn 주석, 내보내기 보고, 프로젝트 저장소 견본.
- **용어집** — 안을 만들었다([`english-ui-glossary.md`](english-ui-glossary.md)) — 소유자가 본다.
- **설명서의 범위** — 작가 설명서에 더해 **[구성] 안내서**(`chapter-layer-guide.md`)까지 옮긴다. README · 개발 문서(`docs/plans` · `design` · `work-orders`
  그 밖)는 한국어로만 둔다(소유자 — 「구성 안내서만 영어로 옮기면 충분합니다」).

## 2. 지금 (2026-11-23에 잰 것 — 주석을 뺀 어림)

  이름. 두 언어로 한 바퀴 돌며 본다(E7).
