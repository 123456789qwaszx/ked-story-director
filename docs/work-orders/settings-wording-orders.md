# 설정 창 다듬기 — 미니맵 감추기 · 「내보내기 (복제할 폴더 선택)」 · 저장 위치 글 걷기 (Z0–Z3) — 2026-11-18

**소유자**:
- 「설정 창에서 [대본] 탭 미니맵 보이기가 아니라, 미니맵 감추기로 해줘. 디폴트값으로 해제되어서 안 보이다가, 체크하면 미니맵을 안 보이게
  하는거지.」

- 「설정 창 안에, project.vnproject.json에 저장됩니다라던지, 기타의 이 PC의 앱 설정에 저장됩니다 프로젝트 파일과 상관없다는 이런 설명은
  필요없어.」

> **상태: 끝 (2026-11-18).**

## 1. 지금

- 「기타」의 「[대본] 탭 미니맵 보이기」는 처음 켜져 있다 — 끄면 지도가 걷힌다.
- 「내보내기」의 머리는 지금 보내는 형식을 말한다(「내보내기 — 작업 폴더에만 냅니다」 · 「내보내기 — 진행 JSON을(를) 보낼 곳에도 냅니다」).
  안의 말은 「보낼 곳」 · 「보내지 않음」이다.
- 묶음마다 어디에 저장되는가를 머리 아래에 적는다(2026-11-17 C3 — 「이건 왜 Ctrl+Z가 안 되지?」를 막으려고).
  - 이 프로젝트: 「project.vnproject.json에 저장됩니다 — 바꾸면 되돌리기(Ctrl+Z)가 되고, File → 저장(Ctrl+S)해야 파일에 남습니다.」
  - 내보내기: 「runtime.target.json(프로젝트 폴더)에 저장됩니다 — …」
  - 기타: 「이 PC의 앱 설정에 저장됩니다 — 프로젝트 파일과 상관없고 …」

## 2. 정한 것

- **「미니맵 감추기」** — 처음 꺼져 있다(지도가 보인다). 켜면 지도가 걷힌다. 누르는 즉시다.
  - 앱 설정은 그대로(`ShowMinimap`)이고 체크가 거꾸로 비춘다 — 옛 설정 파일도 같은 뜻으로 읽힌다.
- **「내보내기 (복제할 폴더 선택)」** — 머리는 이 글 하나다(⛔ 지금 보내는 형식을 말하던 머리는 걷는다). 안의 보이는 말도 「복제할 폴더」 ·
  「복제하지 않음」으로 맞춘다.
  - 그 묶음의 첫 줄은 「작업 폴더(exported/)에는 늘 쓰고, 고른 폴더에는 저장(Ctrl+S)할 때 복제합니다.」 한 줄로 줄인다. 무엇이 「복제」인지
    말하는 줄이라 남긴다.
  - 저장 위치(`runtime.target.json`)는 걷는다.
- **묶음 머리의 저장 위치 글을 걷는다** — 이 프로젝트 · 기타. ⛔ C3의 「묶음마다 어디에 저장되는가를 머리에 적는다」를 뒤집는다.
- 판 크기 풀이, 형식마다의 풀이(진행 JSON · 대사 Yarn이 어디로 가는가)는 그대로다 — 저장 위치가 아니라 무엇을 고르는가의 풀이다.
