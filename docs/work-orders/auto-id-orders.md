# 자동 ID — 챕터 · 장면이 든 에피소드ID와 분기 카드 이름, Yarn 노드 이름은 하나 (I0–I5) — 2026-11-17

`docs/work-orders/scene-required-orders.md` E6을 여기서 한다. 자동으로 붙는 에피소드ID가 `new01` · `new02`…라 챕터가 여럿이면 겹친다 —
게임은 모든 챕터의 Yarn을 한 프로젝트로 컴파일하므로 같은 이름의 노드 둘은 컴파일을 깬다.

> **상태: 끝(I0–I5).** 문서(I5)는 단계마다 함께 고쳤다.

## 1. 정한 것 (소유자 2026-11-17)

| | 내용 |
|---|---|
| 에피소드ID | `{챕터ID}_{장면ID}_newNN` — 예: `ch01_scene01_new03`. 번호는 그 자리(챕터 · 장면)에서 빈 가장 작은 수 |
| 분기 카드 이름 | 같은 규칙 `{챕터ID}_{장면ID}_branchNN`. 장면은 그 카드를 처음 부르는 에피소드(집)의 장면 |
| Yarn 노드 이름 | **프로젝트에서 하나여야 한다** — 챕터를 넘어 겹치면 오류(내보내기를 막는다) |
| 옮기면 따라가나 | **자동 모양 그대로인 ID만** 따라간다 — 에피소드를 다른 장면으로 옮기거나 장면ID · 챕터ID를 바꾸면 새 자리의 이름으로. 같은 되돌리기 칸. 사람이 고친 ID는 건드리지 않는다. 분기 카드도 같은 규칙으로 집을 따른다 |
| 분기 카드 제목 | **제목을 따로 둔다** — 에피소드처럼 이름(= ID = Yarn 노드 이름)과 제목을 나눈다. [대본]은 제목(처음 「새 분기」, 비우면 ID)을 보이고 고치고, ID는 [구성]에서 본다 |

ID를 바꾸는 일 자체는 이미 있다 — `EpisodeRenamer`가 에피소드ID · 간선 · 픽스처 · 카드 이름(= Yarn 노드 이름) · 대사엔트리를 되돌리기 한
칸으로 옮긴다([구성] 에피소드ID 칸이 쓴다). 걸리는 것은 바깥이 옛 ID를 쥐고 있을 때(compositor가 가져간 Yarn의 노드 이름, 게임 세이브)다 —
그래서 아직 아무도 붙들지 않았을 자리표시(자동 모양)만 따라간다.

## 2. 규칙

- **글자** — `{챕터ID}_{장면ID}_new` · `_branch` 앞머리를 Yarn 노드 이름 정규화(`YarnSyntax.SanitizeNodeName` — 공백 · 점 · 하이픈 → `_`)에
  지나게 한다. 장면ID가 `교실 2`여도 ID에 공백이 들지 않는다. 번호는 두 자리 이상(`new01` … `new99`, `new100`).
- **겹치지 않게** — 번호는 그 앞머리에서 빈 가장 작은 수다. 비었는지는 그 챕터의 에피소드ID와 **프로젝트의 모든 카드 이름**으로 본다.
- **장면 없는 에피소드**(명령 수준에서만 생긴다)는 `{챕터ID}_newNN`.
- **자동 모양인가** — 지금 자리(챕터 · 장면)의 앞머리 + 숫자뿐인 꼬리. 다른 자리의 모양이면 이미 그 자리의 것이 아니다(옮긴 뒤 사람이 그대로 둔 것은 따라간다).
- **따라가기** — 에피소드를 다른 장면으로: 새 장면의 다음 번호. 장면ID · 챕터ID 바꾸기: 번호는 그대로(겹치면 다음 빈 수). 집이 옮겨진 분기
  카드도 같은 칸에서.
- **Yarn 노드 이름이 겹친다** — 오류 `YarnNodeNameTaken`. 그 챕터의 에피소드 대사 노드 · 분기 카드가 **다른 챕터**의 것과 같은 이름이면 짚는다
  (같은 챕터 안은 지금처럼 `BranchCardNameTaken`). 글이 상대(챕터 · 카드)를 말하고 [구성] 탭에서 ID를 고치라고 한다.
