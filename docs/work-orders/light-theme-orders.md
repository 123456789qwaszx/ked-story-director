# 화면을 밝게 고정한다 (LT0–LT2) — 2026-11-18

**소유자**: 「네. 밝게 고정해주십시오.」(다크 모드 견적 `docs/design/dark-mode-estimate.md`의 (0)안)

> **상태: 끝 (2026-11-18).**

## 1. 지금

- 앱은 윈도우의 밝게/어둡게 설정을 따라간다(`App.axaml`의 `RequestedThemeVariant="Default"`).
- 어둡게면 틀(메뉴 · 하이어아키 · 인스펙터)만 어두워지고 판(카드 · 미니맵 · 선택지 칸)은 코드에 박힌 밝은 색 그대로다 — 카드 이름이 흰 바탕에
  흰 글(1.07:1)이 되어 읽히지 않는다.
- [구성] 인스펙터의 「▾ 대사」 접기 제목이 부르는 `ThemeForegroundBrush`는 어디에도 정의돼 있지 않아 기본 검정으로 풀린다 — 밝게에서는 우연히
  맞아 보이고, 어둡게에서는 검정 바탕에 검정 글이다.

## 2. 정한 것

- **늘 밝게** — `RequestedThemeVariant="Light"`. 윈도우가 어둡게여도 이 앱은 지금 보던 밝은 화면으로 뜬다. 진짜 다크 모드는 견적의 (2)안
  (설정 창 「기타」에서 시스템 따라가기 · 밝게 · 어둡게)으로, 작가의 요청이 나오면 한 번에 넣는다.
- **빠진 키를 정의한다** — `ThemeForegroundBrush`를 App의 테마 사전에 둔다(밝게 · 어둡게 한 벌씩 — `ThemeBorderLowBrush`와 같은 자리).
- 밝은 화면의 색은 하나도 바꾸지 않는다.
