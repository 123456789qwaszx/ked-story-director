## 1. 단계

| # | 일 |
|---|---|
| FX0 | 지시서 |
| FX1 | **지난 지시서 닫고 치우기** — 2026-08의 지시서 아홉(bool-stat · ease-curve · ease-open · motion-graph · presentation-refresh · depth-level · gesture · dialogue-entry-naming · edge-presentation)과 yarn-output을 걷는다. 그것을 가리키던 코드 주석 · 시험 · 문서의 고리는 걷었다고 적거나 지금 문서로 돌린다 |
| FX2 | **문구 교정** — 저장 뒤 상태줄의 「보낼 곳에도 보냅니다」를 설정 창과 같은 「복제」 말로. 보이는 글의 어색한 꼴(「을(를)」 같은 조사 겹침 · 섞인 말)을 고친다 |
| FX3 | **성능** — 에피소드 수백 개의 판에서 ① 무리(범위 선택 · 이름표) 끌기 ② 카드 글 쓰기 → 인스펙터 반영을 잰다. 느린 곳을 고친다(단계마다 한 커밋) |
| FX4 | **문서 · 주석 바로잡기** — README · ORIENTATION · ARCHITECTURE · 작가 안내 · 챕터 층 안내 · 인계 문서 · 설계 1–6절 · 화면 주석의 틀린 말을 지금 코드에 맞춘다(조사 결과에 따라 한 커밋 또는 몇 커밋) |
| FX5 | **다크 모드 수요 · 견적** — 지금 테마가 어떻게 걸려 있는지, 굳은 색이 몇 군데인지, 비슷한 도구들의 수요, 선택지별 단계 · 시간 · 위험. 문서로 남긴다(`docs/design/dark-mode-estimate.md`). 만들기는 소유자가 정한 뒤 |
| FX6 | **실제 스토리를 툴 프로젝트로** — 첨부된 이벤트 스토리 1–8편(OCR 엑셀)을 챕터 · 장면 · 에피소드로 나누고 선택지 · 조건 · 스탯을 붙여 툴 프로젝트로 짓는다. ⚠ 원문은 상용 게임의 대사라 **저장소에 싣지 않는다** — 프로젝트 폴더를 파일로 건넨다 |
