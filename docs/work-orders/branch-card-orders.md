# 분기 카드 지시서 (B0–B6) — 2026-11-17

**[대본] 판의 카드를 두 종류로 나눈다 — 에피소드와 분기 카드.** 에피소드는 선택지 · 자동 길로 들어가 게임의 「지금 에피소드」가 되고, 분기
카드는 다른 카드의 대사 중 분기점(`<<detour>>`)으로 들렀다 **돌아온다**. 둘은 게임에서 완전히 다른 물건이다.

> **상태: 진행 중.** 1절과 4절은 소유자가 정했다(4절은 다섯 다 제안대로).

## 1. 정한 것 (소유자 2026-11-17)

| | 내용 |
|---|---|
| 나누기 | **종류로 나눈다**(만들 때 정한다). 「분기 추가」는 분기 카드를, [＋ 대사 노드]는 에피소드를 만든다. ⛔ R7 결정 ⑤(2026-09-17 — 「자유 씬 · 조건 노드 · 경유 노드는 한 물건, 판의 카드는 전부 에피소드」)를 **분기 카드에 한해** 뒤집는다 — 경유 노드를 에피소드 + 자동 길로 편 것은 그대로 맞다 |
| 선택지 칸 | 분기 카드에는 **없다** — 분기로 들른 카드의 선택지는 게임에 나오지 않는다(런타임 `SceneRunner`는 지금 에피소드의 대사를 끝까지 튼 뒤 지금 에피소드의 선택지를 띄운다) |
| [구성] 탭 | 분기 카드는 부르는 에피소드 곁에 **점선으로 붙은 작은 카드**, **읽기 전용** — 대본 내용을 볼 수 있다. **분기 조건은 고친다**(지금의 분기 조건 칸 그대로) |
| 진행 JSON | 분기 카드는 **싣지 않는다**(게임은 Yarn 노드만 쓴다) |
| 옛 프로젝트 | **옮기지 않는다** — 옮길 실물이 아직 없다(소유자). 옛 프로젝트의 분기 대상 에피소드는 에피소드 그대로 열리고, 그 분기점은 B2의 검증이 짚는다 |

## 2. 지금 모습 (근거)

- 카드는 모두 `DialogueNode`이고, 챕터 판의 카드는 열 때 전부 에피소드로 올린다(`ProjectEditor.LiftFreeScenes`). 에피소드인지는 챕터의 에피소드 목록과
  카드의 표식(`MarkedEpisodeId`)이 정한다 — `EpisodeNaming` 한 벌(부르는 자리 25곳).
- 분기점은 대사 줄의 확장(`DialogueLineExtension.DetourTargetNodeIds`)에 산다. [구성] 탭은 `ChapterBranchMarkers`로 그것을 읽어 점선과 분기점을 그린다
  (`DrawBranchMarkers` — 지금은 도착이 에피소드 카드다).
- 분기 조건은 분기 카드 대본의 첫머리에 산다(`BranchEntryCondition`) — 종류를 나눠도 그대로다.
- 오늘 앞서 넣은 `ChapterBranchReach`(분기로 들어오는 에피소드를 알림으로)는 분기 대상이 에피소드인 세계의 것이다 — 분기 카드가 서면 걷는다.
- 견본 FestivalEve의 분기 대상 다섯(`Festival_Wrapup_Remade` · `_Sticker` · `Festival_Staffroom_Kasmi` · `_Praise` · `_Pass`)은 지금 에피소드로
  진행 JSON에 실려 있다(들어오는 간선 없음 · 선택지 없음). 런타임 저장소의 게임 폴더(`Assets/Dialogue/ChapterProgression`)에도 같은 진행 JSON이 있다
  — 런타임 코드는 이 Id를 부르지 않는다.

## 3. 설계 — 지킬 것

1. **종류는 저장된 신원이다** — `DialogueNode.IsBranchCard`(판 파일의 카드에 `branchCard: true`, 분기 카드일 때만 쓴다). 노드 종류(`kind: "dialogue"`)는
   그대로 둔다 — 다른 저장소(compositor)가 이 파일을 읽는다(모르는 칸은 지나칠 것으로 보지만 그쪽에서 확인한다). 분기 카드는 챕터의 에피소드가
   아니다 — 에피소드 목록에 없고 표식도 없다. 열 때 에피소드로 올리지 않는다.
2. **잇는 규칙은 편집 명령이 지킨다** — 분기점은 분기 카드에만, 선택지 · 자동 길은 에피소드에만 잇는다. 화면은 틀린 자리에 놓으면 받지 않고 까닭을
   말한다. 분기 카드는 선택지 칸이 없으니 나가는 선택지도 없다.
3. **분기 카드의 장면은 부르는 에피소드의 장면이다** — 저장하지 않고 연결에서 읽는다(판의 장면 테두리 · 대사 Yarn 파일 · 장면 파일이 같은 규칙).
   여러 장면에서 불리면 대본 차례로 첫째 부르는 쪽.
4. **검증** — 분기 카드는 도달성 증명(런타임의 오라클 — 에피소드만) 밖이다. 따로 본다: ① 분기점이 에피소드에 이어져 있다(옛 데이터) → 오류,
   ② 아무도 부르지 않는 분기 카드 · 도달할 수 없는 에피소드(또는 그런 분기 카드)만 부르는 분기 카드 → 4절 A, ③ 줄이 없는 분기 카드 → 오류
   (Yarn 컴파일러가 줄 없는 노드를 빼 `<<detour>>`가 없는 노드를 부른다 — 지금의 「빈 씬」 규칙 그대로).
5. **[대본] 판** — 분기 카드는 모양이 다르다(테두리 · 머리의 「⑂ 분기」, 장면 표 · 선택지 칸 없음). 분기 조건 표시(「⑂ 조건: X」)는 그대로.
6. **[구성] 판** — 분기 카드는 부르는 에피소드의 분기점 곁에 작은 카드로 서고 점선으로 붙는다. 끌어 옮기지 않는다(자리는 그 에피소드를 따라간다).
   누르면 인스펙터에 분기 카드 — 이름 · 부르는 곳 · **분기 조건(고친다)** · 대본(읽기 전용).
7. **내보내기** — 진행 JSON: 분기 카드는 에피소드가 아니라 저절로 빠진다. 대사 Yarn: 분기 카드는 부르는 에피소드의 장면 파일에 노드로 선다(머리 주석
   「// 분기 카드: 이름 — 「부르는 에피소드」에서 들른다」). 장면 파일(`scenes.json`): 4절 D.
8. `ChapterBranchReach` · `EpisodeEnteredByBranch`는 걷는다(안 쓰는 것은 흔적 없이).

| | 물음 | 제안 |
|---|---|---|
| A ✅ 경고 | 아무도 부르지 않는 분기 카드, 도달할 수 없는 곳만 부르는 분기 카드는 | **경고**(내보내기를 막지 않는다) — 분기 카드는 진행 JSON에 없어 게임을 깨지 않는다. 에피소드의 「경로 없음」은 오류 그대로 |
| B ✅ 부르는 에피소드 밑 | 하이어아키(두 탭)에 분기 카드를 | **부르는 에피소드 밑에 「⑂ 이름」 줄로** 보인다 — 누르면 [대본]은 그 카드로 가고, [구성]은 그 분기 카드 인스펙터를 연다 |
| C ✅ 새 분기 카드 | 이어지지 않은 분기점을 판의 빈 곳에 놓으면 | **그 자리에 새 분기 카드를 세우고 잇는다** — 지금은 빈 곳에 놓으면 분기점이 걷힌다. 분기 카드를 지운 뒤 다시 잇는 길이 「분기 추가」뿐이면 분기점이 하나 더 생긴다 |
| D ✅ 싣는다(ked-scenes/2) | 장면 파일(`scenes.json` — AI가 장면마다 연출 초안을 낼 때 읽는다)에 분기 카드의 대사를 | **싣는다** — 부르는 에피소드 아래 `branches: [{ name, lines }]`. 분기 카드 대사에도 연출이 붙어야 한다. 모양이 바뀌므로 형식을 `ked-scenes/2`로 올린다 |
| E ✅ 견본만 고친다 | 견본(FestivalEve · 시험 자료)의 분기 대상 다섯을 | **분기 카드로 한 번 고쳐 둔다**(앱의 옮기기 코드가 아니라 견본 파일만) — 진행 JSON에서 다섯 노드가 빠진다. 런타임 게임 폴더의 사본은 다음 내보내기에 같이 바뀐다 |

## 6. 하지 않는 것 · 남는 위험

- 옛 프로젝트를 옮기는 코드 — 짓지 않는다(1절). 소유자의 시험 프로젝트에 있는 분기 대상 에피소드는 B2의 오류로 짚이고, 분기 카드로 다시 세운다.
- ⚠ compositor(다른 저장소)는 판 파일과 매니페스트를 읽는다 — 새 칸 `branchCard`를 지나치는지, 에피소드가 아닌 카드를 받는지 그쪽에서 확인한다.
- ⚠ 런타임 저장소의 게임 폴더 사본(진행 JSON)은 소유자 PC에서 내보낼 때 바뀐다 — 런타임 시험이 그 노드들을 부르지 않는 것은 확인했다.
