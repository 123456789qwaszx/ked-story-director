# 장면 없는 에피소드를 만들지 않는다 · 낙서판을 걷는다 (E0–E6) — 2026-11-17

**에피소드는 늘 챕터와 장면에 속한다.** 장면 없는 에피소드를 만드는 창구 · 장면을 비우는 창구를 걷고, 챕터가 아닌 판(낙서판 — 새 프로젝트의
「기본 파일」)을 흔적 없이 걷는다. 처음 쓰는 사람을 위해 아무것도 없을 때 [＋ 대사 노드]가 챕터와 장면을 저절로 세운다.

> **상태: 진행 중.** 1절은 소유자가 정했다.

## 1. 정한 것 (소유자 2026-11-17)

| | 내용 |
|---|---|
| 장면 없는 에피소드 | **허용하지 않는다.** ⛔ 2026-11-01(`docs/plans/hierarchy.md` 4절 — 장면ID가 없는 에피소드는 챕터 직속)을 뒤집는다. 그때 허용한 까닭은 「만들 때 장면에 억지로 붙이는 어색함」 하나였다 — 게임에서는 그 에피소드가 보이지 않는 혼자짜리 장면(`__scene_{Id}`)이라 Yarn 파일 · 장면 파일이 하나씩 따로 나가고 메모를 달 자리가 없었다 |
| [＋ 대사 노드] | 고른 장면에 · 아니면 고른 카드의 장면에 · 아니면 **새 장면**을 세워 넣는다(빈 챕터도). 챕터가 하나도 없으면 **챕터 + 장면**을 세운다. 한 되돌리기 칸 |
| 낙서판 | **흔적 없이 걷는다** — 새 프로젝트는 판 없이 시작한다. 챕터가 아닌 판을 위한 코드 · 주석 · 문서 · 시험까지 |
| 옛 데이터 | 이미 장면이 없는 에피소드는 **경고**(내보내기를 막지 않는다 — 게임에서는 혼자짜리 장면으로 돈다). 장면 줄로 끌어 넣어 고친다 |
| 편집 명령 | 장면 없이 에피소드를 만드는 것은 명령 수준에서 그대로 받는다(시험 177곳) — 규칙은 화면의 모든 창구와 검증이 지킨다 |

## 2. 에피소드가 생기는 길 · 장면이 비는 길 (조사)

| 창구 | 지금 | 앞으로 |
|---|---|---|
| [대본] [＋ 대사 노드] — 장면을 골라 둠 | 그 장면 | 그대로 |
| [대본] [＋ 대사 노드] — 장면을 안 고름 | 장면 없음 | 고른 카드의 장면, 아니면 새 장면 |
| [대본] [＋ 대사 노드] — 챕터가 없음 | 「기본 파일」 낙서판에 「장면 N」 카드(에피소드 아님) | 챕터 + 장면 + 에피소드 |
| 하이어아키 챕터 줄 「에피소드 추가」 | 장면 없음 | 걷는다 |
| 하이어아키 장면 줄 · 에피소드 줄 「에피소드 추가」 | 그 장면 | 그대로(장면 없는 에피소드 줄에서는 서지 않는다) |
| 하이어아키 「장면 추가」 | 새 장면 + 첫 에피소드 | 그대로 |
| 열 때 판의 카드를 에피소드로 올림(`LiftFreeScenes` — 옛 데이터 안전망) | 부르는 쪽 장면, 없으면 장면 없음 | 걷는다 |
| 하이어아키 「장면에서 빼기」 · 「장면 풀기」 | 장면을 비운다 | 걷는다 |
| 에피소드 줄을 챕터 줄에 끌어 놓기 | 장면을 비운다 | 받지 않는다(장면 줄에만) |
| [구성] 탭 | 에피소드를 더하는 창구가 없다(하이어아키도 읽기 전용) | 그대로. 「하이어아키 우클릭 「에피소드 추가」」라고 쓴 [구성]의 빈 판 안내 · 주석 · 문서를 「[대본] 탭」으로 분명히 한다 |

## 4. 아직 물을 것 (E6 앞에서)

- ID에 장면을 넣으면 에피소드를 다른 장면으로 옮겼을 때 ID 속 장면이 옛것으로 남는다(ID는 신원이라 안 바뀐다) — 그대로 갈지, 챕터만 넣을지.
- 분기 카드 이름(「분기 N」 — 지우면 번호가 겹칠 수 있다)도 같은 규칙으로 맞출지.
- 챕터를 넘는 Yarn 노드 이름 겹침 검사(게임은 모든 챕터의 Yarn을 한 프로젝트로 컴파일한다)를 넣을지.
