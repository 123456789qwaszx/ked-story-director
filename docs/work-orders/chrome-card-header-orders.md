## 1. 지금

- **File** — 위 띠 맨 왼쪽은 `Menu`의 맨 윗 항목이다. 테마의 바탕이 투명해 이웃 단추([📂 작업 폴더] · [⚙ 설정] — 회색 바탕)와 달리 글자만 보인다.
- **세 줄의 높이**는 위 띠 53(위아래 여백 10 + 단추 32), [구성] · [대본] 탭 48(테마 기본 — 글 24), 툴바 49(위아래 여백 8 + 칸 32)다.
- **카드 머리의 칩 높이**는 칩 안 글이 정한다.
  - 앱 글꼴은 Inter다(`WithInterFont`). 라틴 글자(`scene01` · `ch01_scene01_new01`)는 Inter로, 한글(「시작점」 · 「새 장면」 · 「새 에피소드」)은 Inter에 없어
    시스템의 한글 글꼴로 그려진다.
  - 두 글꼴의 줄 높이가 달라 「ID로 보기」를 켜면 라틴 칩이 한글 칩보다 낮다. 글꼴도 다르다.
- 카드 머리는 한 줄이다 — 칩들 뒤에 에피소드 이름.
- 장면 시작점 칩의 글은 「시작점」이다(2026-11-18 H2 — 소유자가 「장면」이 겹친다고 뗐다).

## 2. 정한 것

- **File은 이웃 단추와 같은 모양이다** — 회색 바탕 · 둥근 모서리 · 같은 높이. 누르면 지금처럼 목록이 펼쳐진다.
- **세 줄을 붙인다.**
  - 위 띠 여백 10 → 4.
  - [구성] · [대본] 탭 글 24 → 18, 높이 48 → 34.
  - 두 탭의 툴바 여백 8 → 4.
  - 단추 · 칸 크기는 그대로다.
- **카드 머리 칩은 높이를 박는다**(16 — 글은 가운데). 글이 무엇이든 칩 상자가 같다.
- **카드 머리는 한글 먼저인 글꼴 한 벌로 그린다.**
  - 차례는 맑은 고딕 → Apple SD Gothic Neo → Noto Sans KR · CJK KR → 앱 기본.
  - 한글 글꼴이 라틴 글자도 그리므로, ID로 보든 이름으로 보든 칩 · 이름이 같은 글꼴이다.
  - 앱 전체의 글꼴은 바꾸지 않는다 — 판 카드 머리만이다.
- **에피소드 이름은 칩 아래 둘째 줄이다**(이름 · ID 한 줄 — 「ID로 보기」가 무엇을 보일지 정한다).
- **「시작점」 → 「장면 시작점」** — ⛔ H2를 뒤집는다.
