# 보낼 곳 — 위 띠의 게임 폴더 단추를 설정 창의 형식별 보낼 곳으로 (G0–G3) — 2026-11-17

**소유자**: 툴 위 띠의 [🎮 게임 폴더…]를 바깥에 드러내는 대신, 설정 창 안에서 형식(진행 JSON · 장면 파일 · 대사 Yarn)마다 그 형식을 낼 폴더를
정한다.

> **상태: G0 지시서.**

## 1. 지금 (조사)

| 형식 | `exported/` | 게임 폴더 | 언제 |
|---|---|---|---|
| 진행 JSON `{챕터}.progression.json` | 늘 | 한 벌 더(평평하게) | **모델이 바뀔 때마다**(검증을 통과한 챕터만) |
| 장면 파일 `{챕터}.scenes.json` | 늘 | 안 씀 | 같음 |
| 대사 Yarn `yarn/{챕터}_{장면}.yarn` | 늘 | 안 씀(연출 든 Yarn과 겹친다 — 11-17 소유자) | 같음 |

- 게임 폴더는 프로젝트 폴더의 `runtime.target.json`(`gameFolder`, 프로젝트 기준 상대 경로)에 산다 — **compositor도 같은 파일을 읽어** 제 Yarn을
  그 폴더에 쓴다.
- 단추 툴팁 · 상태줄 · `runtime.target.json`의 안내는 「저장할 때마다」라고 하지만 실제로는 바뀔 때마다 썼다.
- 프로젝트에서 사라진 챕터의 게임 폴더 파일은 걷는 `exported/` 사본과 바이트가 같을 때만 함께 걷었다(게임 폴더는 다른 프로젝트 · 견본과 나눠 쓴다).

## 2. 정한 것 (소유자 2026-11-17)

| | 내용 |
|---|---|
| 모양 | **`exported/`는 그대로**(툴의 작업 사본 — 늘 쓴다, 지난 파일 걷기도 그대로). **형식마다 「보낼 곳」 폴더**를 켜고 고른다. 진행 JSON의 보낼 곳이 지금의 게임 폴더다 |
| 언제 | `exported/`는 지금처럼 바뀔 때마다. **보낼 곳은 File → 저장(Ctrl+S) 때만** — 저장 안 된 중간 상태가 런타임 저장소에 나가 유니티가 다시 읽거나 git에 잡히는 일을 막는다 |
| 저장 자리 | **`runtime.target.json`** — 프로젝트마다, 상대 경로. `gameFolder`(진행 JSON — compositor가 읽는다)는 뜻을 그대로 두고 칸을 더한다: `scenesFolder` · `dialogueYarnFolder`(compositor의 Yarn과 헷갈리지 않게 「대사」를 이름에 넣는다). 모르는 칸은 지킨다(다른 툴의 것) |

## 3. 규칙

- **보내기 = `exported/`를 비추기** — 저장 뒤의 내보내기가 끝난 `exported/`에서 형식마다 그 파일들을 보낼 곳으로 옮겨 쓴다(같은 바이트면 안 쓴다).
  검증에 걸린 챕터는 `exported/`의 옛 파일이 그대로라 보낼 곳에도 옛 것이 남는다(지금과 같다 — 런타임은 늘 「한 번은 옳았던」 판을 읽는다).
- **보낸 기록**(`exported/.delivered.json` — 보낸 경로와 그 바이트의 지문). 다음 보내기에서 이번에 안 보낸 파일 가운데 **기록과 바이트가 같은 것만**
  걷는다 — 이 툴이 보낸 그대로라는 뜻이다. 사람이 고쳤거나 남의 파일이면 둔다. **보낼 곳을 바꾸거나 끈 형식은 옛 폴더를 건드리지 않는다**(기록만 놓는다).
- **없는 폴더는 만들지 않는다**(지금과 같다 — 다른 PC에서 상대 경로가 엉뚱한 자리를 가리킬 때 산출물이 아무 데나 쌓인다). 보고가 말한다.
- **대사 Yarn을 게임 폴더(진행 JSON의 보낼 곳)로는 받지 않는다** — 게임의 Yarn 프로젝트가 compositor의 연출 든 Yarn과 같은 노드 이름을 둘 읽어
  컴파일이 깨진다. 설정 창이 거절하고 까닭을 말한다.
- 보낸 결과는 **검증 보고**의 「나간 자리」 줄에 선다(「보낸 곳 → 진행 JSON ../… · 장면 파일 … · 대사 Yarn …」 · 못 쓴 것 · 없는 폴더).
