# 장면 파일(`{챕터}.scenes.json`)을 걷는다 (N0–N1) — 2026-11-18

**소유자**: 「진행 JSON과 장면 파일이 있는데 이 두개의 역할이 뭡니까? 또 장면파일은 필요한게 맞습니까? … 아마 compositor에서 쓰도록 하는 그런 것
같은데, 불필요한 것 아닙니까?」 → 까닭을 말씀드리고(아래 1절) 「걷읍시다.」

> **상태: 진행 중.**

## 1. 지금 — 왜 걷는가

- 장면 파일은 2026-11-16(`scene-notes-orders.md` S5)에 「AI가 장면 하나씩 연출 초안을 낼 때 읽는 파일」로 섰다 — 장면마다 장면 메모 · 에피소드 지시 ·
  대사 줄(LineId · 화자 · 글) · 분기 카드.
- 이튿날(11-17) 대사 Yarn(`yarn/{챕터}_{장면}.yarn` — 장면 = 파일)이 서며 거의 다 겹쳤다: 장면 이름 · 장면 메모 · 에피소드 제목 · 에피소드 지시(주석),
  대사 줄과 LineId(`#line:`) · 조건 · 분기 카드. 장면 파일에만 있는 것은 챕터 표시 이름 · 장면의 첫 에피소드 · 주인 없는 장면 메모뿐이다(셋 다 연출을
  붙이는 데 쓰이지 않는다 — 주인 없는 메모는 툴 안에서 보인다). 그때의 지시서(`yarn-output-orders.md` 9)는 「Yarn과 겹치는 것을 걷을지는 2단계에서」로
  미뤘다.
- 읽는 곳을 찾지 못했다 — 이 세션이 닿는 저장소(런타임 · 작업공간 · staging-extractor · 캐릭터 리그 툴)에 `scenes.json`을 읽는 코드가 없고, 코드 검색도
  0건이다. compositor가 읽는 것은 `runtime.target.json`의 `gameFolder`(진행 JSON의 보낼 곳)다.
