# 스토리 디렉터 0.4.0

## 받을 파일

- `StoryDirector-0.4.0-windows.zip` — Windows. 압축을 풀고 `StoryDirector.exe`.
- `StoryDirector-0.4.0-mac.zip` — 맥. 압축을 풀고 「응용 프로그램」 폴더로 옮긴 뒤 연다.

두 zip 안에 「먼저 읽어주세요.txt」 · 「Read me first.txt」(영어) · 「THIRD-PARTY-NOTICES.txt」가 함께 든다.

## ⚠ 앞 판과 섞어 쓰지 마세요

**0.4.0은 0.3.x까지 만든 프로젝트를 열지 않습니다** — 프로젝트 형식이 4에서 5로 바뀌었습니다. 열면
「형식 버전 4 프로젝트는 열지 않습니다 — 이 툴은 형식 5만 엽니다.」가 뜹니다. 거꾸로 0.3.x도 0.4.0이 저장한 프로젝트를 열지 않습니다.
옮기는 길은 두지 않았습니다 — 0.3.x 프로젝트는 0.3.x로 계속 쓰고, 0.4.0에서는 새 프로젝트로 시작합니다.

## 달라진 것

- **프로젝트 형식이 바뀌었습니다(5).** 프로젝트 안에 숨어 있던 「조건 공급」 노드(챕터 조건의 사본)가 없어지고, 대사 · 분기 카드의 조건이
  챕터 조건을 이름으로 바로 가리킵니다. 화면에서 조건을 걸고 고치는 방법은 그대로입니다.
- **진행 코어의 거절 사유가 영어로 나옵니다.** 검증 보고의 「진행 코어가 이 챕터를 싣지 못합니다 — …」 뒤의 사유는 화면 언어와 상관없이
  영어입니다(게임 로그와 같은 문장). 영어 화면에 한국어가 남지 않습니다.

## 고친 것

- 줄 간격 · 글자 크기 · 글꼴 · 굵게를 바꾸면 카드의 글 맞춤(가로 · 세로)이 곧바로 다시 맞습니다.
- 에피소드 제목을 두 번 눌러 고칠 때 이름 칸이 카드 너비만큼 서지 않고 글만큼 섭니다 — 쓰는 대로 늘고 제목 자리에서 멈춥니다.
- 선택지 줄기가 카드 가운데가 아니라 카드 왼쪽의 늘 같은 자리에 섭니다 — 카드를 넓혀도 선택지가 화면 밖으로 밀려나지 않습니다.
