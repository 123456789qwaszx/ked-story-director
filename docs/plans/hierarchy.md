# 우측 기둥을 하이어아키 + 인스펙터로 (2026-10-30)

> 소유자: *"이제 챕터 그래프와 연출 그래프의 우측column을 하이어아키+ 인스펙터 방식으로 바꾸자. 현재 보면,
> 챕터/장면/에피소드로 나뉘어져 있는데, 이걸 유니티 하이어아키처럼 챕터를 부모로 하는 장면이 있고, 이 장면에
> 포함된 에피소드들을 모으는 방식으로 하려고 합니다."*

## 0. 한 줄

두 그래프의 옆 기둥이 **하이어아키 · 인스펙터**가 된다(처음에는 오른쪽 위 · 아래였고, 같은 날 하이어아키를 판 왼쪽으로 옮겼다 — HY5). 하이어아키는 유니티처럼 접었다 펴는 한 그루
`프로젝트 → 챕터 → 장면 → 에피소드`이고, **무엇을 고르든 인스펙터가 그것을 보인다**.

```text
▼ 프로젝트 이름                         ← 고르면: 화자
  ▼ 챕터1                               ← 고르면: 조건 · 스탯
    ▼ 장면 1                            ← 고르면: 장면 이름(그 장면 전체)
        ⌂ 장면 1                        ← 고르면: 챕터 그래프 = 구조 / 연출 그래프 = 대사
        · new02 (떼어냄)
    ▶ 장면 4
  ▶ 챕터2
```

## 1. 결정 (소유자 2026-10-30)

| | 무엇 | 결정 |
|---|---|---|
| HY-D1 | 화자 · 챕터 탭 | **선택에 따라 인스펙터** — 맨 위 프로젝트 줄을 고르면 화자 목록, 챕터 줄을 고르면 그 챕터의 조건 · 스탯. 탭은 걷는다 |
| HY-D2 | 에피소드를 골랐을 때 | **탭마다 제 일** — 챕터 그래프 인스펙터는 구조(이름 · 장면 · 선택지 · 대사 미리보기), 연출 그래프 인스펙터는 대사 줄 편집(지금 곁기둥) |
| HY-D3 | 트리 편집 | **단계별로 되살린다** — 먼저 보기 · 선택, 다음에 우클릭(장면 · 에피소드 추가/삭제) · 끌어 옮기기 · 이름 바꾸기 · 접힘 기억 |

그 밖의 규칙(옛 [대본] 탭 탐색기 규격 [R6-explorer.md](R6-explorer.md)을 잇는다):

- **장면은 엔티티가 아니다** — 장면 줄은 `ChapterSceneGrouping`이 그릴 때마다 묶는 투영이다. 정본은 에피소드의
  `SceneId` 하나다.
- **장면ID를 하나도 안 적은 챕터는 장면 단을 생략**한다(에피소드마다 제 장면이라 장면 줄이 에피소드 수만큼 서면
  노이즈다). 하나라도 적혀 있으면 전부 장면 단으로 보인다. 안 적은 것은 `미지정 · {에피소드}`.
- `__scene_*`(내부 발급 장면 Id)은 사람에게 보이지 않는다.
- 장면 루트(밖에서 들어오는 자리)는 `⌂`, 들어오는 자리가 둘인 장면은 `⚠`.
- **접기는 삼각형만** 한다 — 이름 쪽은 고르기 · (뒤에) 끌기 · 두 번 눌러 이름 고치기를 받는다.
- **고르는 것으로는 줄을 다시 세우지 않는다**(칠만 한다) — 다시 세우면 더블클릭의 둘째 누름이 새 컨트롤에 떨어진다.
- **다시 그려도 접힘이 안 풀린다.** 처음에는 고른 것이 든 챕터 · 장면만 펴진다.
- ⚠ 옛 규격은 *"고를 수 있는 것은 에피소드뿐"*이었다 — 인스펙터가 생기며 뒤집혔다(HY-D1). 모든 줄을 고른다.

## 3. 장면 접기 (SF — 2026-10-30)

소유자: *"하이어 아키에서, 장면, 챕터 단위로 접는 옵션을 추가해줘. 유니티의 하이어아키에서 보이게 하고 안보이게 하는거랑
비슷하게 하되, 접힌 상태로 간선의 연결을 드러내줘야 해. 챕터가 접히는 건 현재를 유지하되, 챕터 내의 일부 장면만 접었을
경우, 접은 장면을 간소화 시키도록 해줘."*

| | 규칙 |
|---|---|
| 상태 | 판 접기(`ExpandedFileIds`)와 같은 **작업 상태**다 — 저장 · 되돌리기 대상이 아니다. 열쇠는 (판 Id, 장면ID)라 챕터 이름이 바뀌어도 따라간다(`AuthoringSession.CollapsedScenes`) |
| 닿는 곳 | 펼친 판 안의 장면만. 판째 접힌 판은 지금의 판 상자 그대로이고, 장면ID를 하나도 안 적은 챕터는 하이어아키에 장면 단이 없어 접을 장면도 없다 |
| 상자 | `CollapsedSceneProjection` — 장면의 카드들이 서던 자리의 왼쪽 위에 선다(다른 카드는 안 움직인다). 머리 = 장면 이름 · 노드 수 · 안쪽 길 수, 줄 = 판의 노드 순서(머리글 줄이 없다 — 상자 하나가 장면 하나다). 치수가 판 상자와 같아 간선 끝 셈법이 하나다. 끌면 그 장면의 카드들이 함께 옮겨진다 |
| 간선 | 밖과 잇는 분기 선은 그 줄의 점에(`CollapsedSceneNodeOutput/Input`). 선택지 길(레인)은 카드에서 내려와 줄 가장자리로 들고(화살촉), 줄에서 나가 도착 카드의 접점이나 다른 상자의 줄로 든다 — 레인이 상자 폭 안으로 내려오면 나아가던 쪽 바깥으로 비킨다(상자 뒤로 사라지지 않게) |
| 안쪽 길 | 장면 안끼리의 분기 선 · 선택지 길은 **그리지 않는다** — 간소화가 뜻하는 바다. 상자 머리의 「안쪽 길 N개」가 센다. 줄의 점(들고 나는 수)도 그려지는 것만 센다 |
| 손짓 | 판: 장면 이름표(「장면 X ⌄」)를 누르면 접힌다 · 상자를 두 번 누르면 펴진다 — 챕터 이름표 · 판 상자와 같은 짝. 하이어아키: 눈(SF2) |
| 챕터 그래프 | 해당 없음 — 챕터 그래프에는 접을 판이 없다. 눈 기둥은 연출 그래프의 하이어아키에만 선다 |
