# 한 줄에 분기 여럿 — 계획과 단계

> 2026-10-29 소유자: *"구조상 현재 하나의 줄에 단 하나의 분기만을 걸 수 있는데, 이거 구조를 하나의 줄에 여러개의 분기가 있을
> 수 있게 할 수도 있어?"* → 검토(의미는 "차례로 다녀오기"를 추천) → *"예. 이대로 진행합시다."*

## 1. 왜 하나뿐이었나

- 줄마다 다녀올 카드 칸이 **하나**였다(`DialogueLineExtension.DetourTargetNodeId`).
- 분기를 가리키는 열쇠가 **줄 Id 하나**였다 — 연출 그래프의 포트 · 선 모양 · 챕터 그래프의 분기 점선 · 분기 지우기 · 다시 잇기가
  모두 줄로 분기를 찾았다.
- 편집 명령(`AddBranchMarker`)과 줄 메뉴가 *"한 자리에 하나만"*으로 거절했다.

게임 쪽은 이미 된다 — 분기는 Yarn에 조건 없는 `<<detour 카드>>` 한 줄로 나가고, 진행 JSON(유니티 수입물)에는 실리지 않는다.

## 2. 결정

| | 무엇 | 결정 | 까닭 |
|---|---|---|---|
| B-D1 | 뜻 | **차례로 다녀온다** — 한 줄 앞의 분기 A · B는 `<<detour A>>` → `<<detour B>>` → 그 줄. 각자 제 첫머리 조건(챕터 그래프 분기 패널)으로 들어갈지 정한다 | "조건은 다녀갈 곳에 산다"(2026-09-18)를 그대로 지킨다. 그중 하나만 가게 하려면 조건을 서로 겹치지 않게 건다 — 부르는 쪽에 if/elseif를 되살리지 않는다 |
| B-D2 | 담는 그릇 | `DialogueLineExtension.DetourTargetNodeIds` — 목록, 순서가 다녀오는 차례. 같은 줄에 같은 카드는 두 번 들지 않는다 | |
| B-D3 | 신원 | 분기 하나 = **줄 + 다녀갈 카드** (`ExitPort.DetourKey` = `{줄}>{카드}`). 포트 열쇠 · 선 모양 열쇠 · 챕터 표식 · 분기 지우기가 이것으로 찾는다. 옛 선 모양 열쇠(`detour:{줄}`)는 읽을 때 그 줄의 첫 분기가 이어받는다 | 줄만으로는 어느 분기인지 모른다. 다녀갈 카드는 분기마다 새로 서므로 둘이면 하나를 가린다 |
| B-D4 | 파일 | `detour` 칸이 하나면 **문자열**(그전과 같은 바이트), 여럿이면 **배열**. 형식 번호는 그대로 | 분기 하나인 프로젝트 · compositor 발행 결과는 다시 써도 그대로이고 결과 해시도 그대로다(새 버전이 안 생긴다). 둘 이상을 쓴 파일은 지금 배포된 옛 도구로는 열리지 않는다 — 그래서 compositor를 먼저 내보낸다 |
| B-D5 | 편집 명령 | `AddBranchMarker`는 이미 분기가 있는 줄에도 하나 더 세운다(그 뒤에). `RemoveBranchMarker(카드, 줄, 다녀갈 카드)`. 포트로 바꾸면 그 분기만 제자리에서 바뀌고(선 모양도 따라간다), 줄만 주면 더하거나(이미 있으면 그대로) 그 줄의 분기를 모두 끊는다 | |
| B-D6 | compositor | 원고 · 발행 결과의 목록을 읽고 `<<detour>>`를 차례로 낸다. 무대 미리보기는 줄 앞 분기를 따라가지 않는다(재생 경로는 조건 갈래 출구만 탄다) — 바꿀 것이 없다 | 경계: compositor는 원고를 읽기만 한다 |

## 3. 단계

한 단계 = 커밋 하나, CI(Windows) 녹색을 보고 다음으로.

| | 무엇 | 상태 |
|---|---|---|
| B1 | **compositor** — 목록 읽기(원고 · 결과) · 문서와 Yarn에 `<<detour>>` 차례로 · 포트 신원 | compositor `bfb8243` (run 13) |
| B2 | **director 데이터** — 모델 · 저장 · 편집 명령 · 흐름 · 포트와 선 모양 열쇠 · 챕터 표식. 화면은 아직 줄에 하나(곁기둥이 둘째를 막는다) | `d418b5f` (run 57) |
| B3 | **director 화면** — 줄 앞에 분기 카드 여러 장(장마다 ✕ 지우기) · ＋ 분기 추가가 언제나 선다 · 챕터 그래프 분기 점선의 신원 · 둘째 분기 카드는 원본 오른쪽 열의 아래로 쌓인다 | 이번 |
